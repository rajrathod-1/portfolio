# Raj Rathod - Portfolio Website

A modern, animated portfolio website built with React, TypeScript, Vite, Tailwind CSS, and Framer Motion.

## 🚀 Features

- **Terminal-Inspired Design**: Interactive terminal-style interface with animated name transitions
- **Smooth Animations**: Powered by Framer Motion for fluid, professional animations
- **Responsive Layout**: Mobile-first design that looks great on all devices
- **Interactive Experience Timeline**: Visual chart showing career growth
- **Project Showcase**: Grid and spotlight views for project presentations
- **Skills Display**: Comprehensive list of technologies and tools

## 📋 Prerequisites

Before you begin, ensure you have the following installed:
- [Node.js](https://nodejs.org/) (version 18 or higher)
- npm (comes with Node.js)

## 🛠️ Installation

1. **Navigate to the project directory**:
   ```powershell
   cd 'c:\Proofpoint\Personal Website'
   ```

2. **Install dependencies**:
   ```powershell
   npm install
   ```

## 💻 Development

To run the development server:

```powershell
npm run dev
```

The website will be available at `http://localhost:5173`

## 🏗️ Build

To create a production build:

```powershell
npm run build
```

The build files will be in the `dist` directory.

## 📦 Preview Production Build

To preview the production build locally:

```powershell
npm run preview
```

## 🎨 Customization

### Personal Information
- Edit `src/App.tsx` to update your name, bio, and contact information
- Update social links (LinkedIn, GitHub, Email) in the Connect section

### Work Experience
- Modify `src/scenes/experience.tsx` to add/edit work history
- Update the `experienceData` array with your career milestones

### Projects
- Edit `src/scenes/projects.tsx` to showcase your projects
- Add project descriptions, technologies, and links

### Skills
- Update `src/scenes/tools.tsx` to list your technical skills
- Add or remove tools as needed

## 🎯 Project Structure

```
src/
```
